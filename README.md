# Sistema de Peaje Vehicular Inteligente IoT (Android + Arduino Uno R4 WiFi)

Proyecto de control de acceso vehicular autónomo y telegestión móvil en tiempo real.

## Stack Tecnológico
* **Frontend Móvil:** Android Studio, Kotlin, Jetpack Compose, Retrofit2 / WebSockets.
* **Hardware IoT:** Arduino Uno R4 WiFi (Renesas RA4M1 + ESP32-S3), TCRT5000, SG90, SW-420, TTP223, LDR.
* **Seguridad:** Cifrado TLS 1.3, autenticación robusta AAL2 (MFA / TOTP RFC 6238) y directrices ISO 27400:2022.

## Requisitos de Ejecución
* Android SDK 34+
* Dispositivo físico o emulador Android (API 34/35)
